# Python Math and Greeting Program

This project is a simple Python application that performs basic mathematical operations and generates customized greeting messages.

## Features
- Performs addition, subtraction, multiplication, and division
- Generates personalized greeting messages
- Beginner-friendly Python project

## Technologies Used
- Python

## How to Run
1. Clone the repository
2. Open the project folder
3. Run the Python file using:
   python main.py
